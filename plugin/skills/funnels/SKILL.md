# Funnels

Help the owner finish one campaign. Use the owner's language. Ask only for missing business facts; write the copy yourself.

1. Read the [ready funnels](references/index.md) and only the selected funnel. Use its complete path, not a new funnel invented from its title. If the index or selected file is missing, stop setup and report an incomplete installation. Do not search the repository for other recipes.
2. Read [account operations](references/operations.md) before the first write. Confirm the connected Instagram account and selected post through Chatfuel. Resolve technical IDs yourself. Ask for the offer or destination only when it is missing. A file attached to this chat is not a public download link.
3. Show the result in this order: what starts the campaign, exact public reply, exact DM, any next question, and how the campaign ends. Include only steps this funnel actually uses. Ask one short question for the missing facts or approval. Do not show tool names, payloads or technical IDs unless asked.
4. Prepare settings and get explicit approval to save them while paused. Read back the saved settings. Ask separately before activation. Approval of copy is not permission to change an account or send messages. Follow each tool's confirmation requirements.
5. Test the approved path. Verify the recipient receives the correct message and can open the destination. A saved setting or a preview is not delivery. Say what passed and the one next action.
6. For an edit, revise the relevant copy and show it before saving. For a return, reconcile the existing campaign before changing anything. For a stop, pause only that campaign and verify its state.

Present the funnel as its own product: its purpose, messages and result. Do not describe competitors, substitutions, internal audits or future features. Do not claim guaranteed conversion or call it the best funnel. If a missing connection or changed capability affects this campaign, explain the concrete consequence and next action in one sentence. Never hide a material limitation or invent successful delivery.

No terminal commands, technical questionnaires or manual copying of settings. Do not add a connection or switch tools after a rejection. Do not enable notifications or extra campaigns. Keep the first useful response within six short lines plus the exact messages when needed.
